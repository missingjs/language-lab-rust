# Project 1: CLI TODO Tool

## Goal

Build a command-line TODO app.

Features:

```text
todo add "learn Rust"
todo list
todo done 1
todo remove 1
```

## Focus

- Cargo
- structs
- enums
- ownership basics
- file I/O
- JSON or TOML serialization
- `Result`
- tests

## Completion Standard

```text
Tasks persist to disk.
Errors are handled with Result.
Core logic is tested.
The CLI is usable without panics.
```
