# Project 2: Log Analyzer

## Goal

Build a tool that reads a log file and prints statistics.

## Focus

- `std::fs::File`
- `BufReader`
- iterators
- string parsing
- maps
- error handling
- streaming rather than loading everything into memory

## Stretch Goals

```text
Support large files.
Output JSON.
Benchmark parsing performance.
```
