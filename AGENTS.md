# Agent Guidelines

Read the [project README](README.md), [shared course requirements](projects/README.md#environment-and-shared-completion-requirements), and the relevant assignment README before making changes. Follow those documents for toolchains, implementation requirements, and verification commands; keep those details there rather than duplicating them here.

- Limit changes to the requested assignment or documentation task. Do not implement other exercises or add a root workspace unless requested.
- When reviewing learner code, explain the cause of a problem and the reasoning behind a fix. Keep changes focused so the learner can follow them.
- When editing the curriculum, keep numbering, prerequisites, cross-links, and the course index consistent. Update the document that owns a requirement instead of copying it elsewhere.
- Run applicable checks from the affected package or workspace. For documentation-only changes, check links and consistency.
- In the final response, summarize changes, report verification performed, and identify any checks that could not be run.
